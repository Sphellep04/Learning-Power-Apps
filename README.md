# Learning Power Apps

This repository tracks an 8-week Power Platform learning project focused on an Employee Asset + Leave Tracker for a realistic Namibian SME context.

## Project goal

The aim is to build a small, end-to-end solution that covers the core Power Platform building blocks:

- Dataverse data modelling
- Canvas and model-driven apps
- Power Automate workflows
- Power BI reporting
- Copilot Studio conversational AI
